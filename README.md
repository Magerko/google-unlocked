# Google Unlocked

Расширение для Firefox, Chrome и Edge. Показывает в Google домены, удалённые из выдачи по жалобам DMCA: читает ссылки на жалобы Lumen, собирает домены и добавляет ссылки для поиска по каждому сайту. Результаты сохраняются в кэше на 30 дней.

Для reCAPTCHA v2 на Lumen есть автоматическое решение локальными ONNX-моделями. Модели входят в репозиторий; платные сервисы и ключи для распознавания не нужны.

## Требования

- Для сборки: Node.js 20+ и npm.
- Для локального решения капчи: Windows 10/11, Python 3.12 и Windows PowerShell 5.1.
- Firefox 128+ либо актуальный Chrome / Edge.

Без локального обработчика расширение тоже работает, но капчу нужно проходить вручную. Установщик обработчика рассчитан на Windows.

## 1. Скачать и собрать

Скачайте репозиторий через **Code → Download ZIP** и распакуйте в постоянную папку или используйте Git:

```powershell
git clone https://github.com/Magerko/google-unlocked.git
cd google-unlocked
npm ci
npm run build
```

Если скачали ZIP, откройте терминал в распакованной папке и выполните последние две команды. Готовые файлы появятся в `dist/`.

## 2. Установить расширение

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите `dist/firefox/manifest.json`.

После перезапуска Firefox временное дополнение нужно загрузить снова. Для постоянной установки требуется подписанная Mozilla сборка; в этом репозитории её нет.

### Chrome / Edge

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное»** и выберите папку `dist/chrome`.

Не включайте одновременно несколько копий Google Unlocked.

## 3. Подключить автоматическое решение капчи

В терминале из корня проекта выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\native\install.ps1
```

Установщик создаст Python-окружение, установит зависимости, соберёт локальный обработчик и зарегистрирует его для текущего пользователя Firefox, Chrome и Edge. Права администратора не нужны. Для загрузки зависимостей при установке нужен интернет.

Если команда `py` недоступна, укажите путь к Python:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\native\install.ps1 -Python "C:\Python312\python.exe"
```

Откройте настройки Google Unlocked:

- Firefox: `about:addons` → Google Unlocked → **Настройки**.
- Chrome / Edge: страница расширений → Google Unlocked → **Параметры расширения**.

Нажмите **«Проверить модели»**. Должно появиться **«Обе модели готовы к работе»**. Автоматическое решение включено по умолчанию; его можно отключить галочкой.

Не перемещайте папку проекта после установки обработчика. Если перенесли её — запустите установщик заново.

## Как пользоваться

1. Выполните поиск в Google. Нужна выдача с уведомлением об удалённых результатах и ссылками на Lumen.
2. Расширение загрузит жалобы и покажет блок с доменами, количеством URL и ссылками «искать на сайте».
3. Если Lumen запросит проверку, откроется его вкладка. Дождитесь решения капчи: одна попытка занимает до 110 секунд.
4. После успешного прохождения расширение вернётся к выдаче и продолжит загрузку. При ошибке капчу можно решить вручную.

Если в выдаче нет ссылок на жалобы Lumen, дополнение ничего не добавляет. Без исследовательского токена обычно доступны домены и количество URL, а не полные адреса удалённых страниц.

## Токен Lumen — необязательно

[Исследовательский токен Lumen](https://lumendatabase.org/pages/researchers#key) можно вставить в настройках. В этом режиме расширение запрашивает API напрямую и может показывать полные URL. Если токен отклонён, используется обычная загрузка через вкладку.

Токен хранится локально в настройках браузера и передаётся только Lumen. Не добавляйте его в файлы проекта.

## Ограничения

- Расширение ограничивает обычную загрузку до 9 запросов в минуту и 28 в час. При исчерпании лимита показывает время продолжения и ждёт. Сервер Lumen может вводить собственные ограничения.
- Поддерживается reCAPTCHA v2 с сетками 3×3, подгружаемыми плитками и поддерживаемыми моделью заданиями 4×4. Другие типы капчи не поддерживаются; распознавание может ошибаться.
- Автоматическое решение работает только на странице проверки Lumen. Anubis выполняется браузером обычным способом.
- Изображения капчи передаются локальному процессу через Native Messaging. В этой реализации нет отправки изображений в сторонний сервис распознавания.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| «Проверить модели» возвращает ошибку | Запустите `native/install.ps1` повторно и проверьте, что папку проекта не перемещали. |
| В Google нет блока | В выдаче должны быть ссылки на жалобы Lumen. Обновите страницу после загрузки расширения. |
| Капча не решается | Проверьте галочку автоматического решения и последний статус в настройках. При необходимости решите вручную. |
| Сообщение о лимите Lumen | Дождитесь указанного времени; повторное обновление не снимает лимит. |
| Firefox потерял расширение после перезапуска | Снова загрузите `dist/firefox/manifest.json` как временное дополнение. |

Для ошибок Firefox откройте `about:debugging` → Google Unlocked → **«Исследовать»** → **«Консоль»**. В Chrome / Edge откройте страницу расширений и консоль service worker Google Unlocked.

ID штатной сборки Chrome / Edge: `mifgnjonedpicacfieeabbfpffednjif`. Если ваш ID отличается, передайте его установщику параметром `-ExtensionId ВАШ_ID`. Firefox использует `google-unlocked@local`.

## Обновление и проверки

После обновления исходников:

```powershell
npm ci
npm test
npm run build
```

Перезагрузите расширение на странице управления дополнениями и обновите вкладки Google / Lumen. Если изменились Python-зависимости или расположение проекта, повторно запустите установщик.

Проверки обработчика после его установки:

```powershell
.\native\.venv\Scripts\python.exe -m unittest discover -s native -p test_host.py
```

## Userscript

Альтернативный вариант — `dist/google-unlocked.user.js` для Tampermonkey или Violentmonkey. Он создаётся той же командой сборки, но не подключает локальные модели. Передача cookie Lumen в этом варианте не проверена.

## Состав проекта и источники

- `src/` — общая логика обработки выдачи и жалоб.
- `extension/` — расширение и настройки браузера.
- `native/` — локальный обработчик, установщик и модели.
- `userscript/` — вариант для менеджера пользовательских скриптов.
- `test/` — тесты и небольшие тестовые страницы.

Сборки `dist/`, зависимости, виртуальное окружение и машинные настройки генерируются локально и не входят в Git.
